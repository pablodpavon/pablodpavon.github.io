A new request hidden in a closing comment

Originally posted on LinkedIn on 23 November 2026.

An AI assistant closed a ticket on our task board and tucked a brand-new request into the closing comment.

The board is new. I built it for NexYn last week, so the people on it, each working with their own Claude, see the same tasks. Every open ticket has an owner and a date, and the assistants can open, update and close tickets.

A closed ticket drops out of view. I only found the request because I went through what the other side had done that morning.

The instructions said a new task gets created right away. They didn't say a comment doesn't count. Now they do: a new request is always a new ticket, with an owner and a date. Never a comment, and never the closing note.

The same day I added a box at the top of the board: work you asked for that the other side has finished. No emails. Each person's assistant is told to bring it up at the start of the next session.

If AI assistants share your task list, which rule did you have to write down first?
