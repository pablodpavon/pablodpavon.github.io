Reporte de KPIs con IA que verifica sus números

AI KPI report that checks its own numbers

Qué haceWhat it does

Un LLM redacta el comentario de KPIs y un control prueba cada cifra contra los datos: que exista, que sea de la métrica y el período correctos, y que "subió" coincida con el dato. Si un número falla, no se publica nada.

An LLM drafts the KPI commentary and a checker tests every figure against the data: it must exist, belong to the right metric and period, and "rose" must match the data. If one number fails, nothing is published.

Qué corre soloWhat runs on its own

Una corrida programada genera datos nuevos de la tienda sintética, recalcula los KPIs, redacta el comentario y pasa el control. La última corrida figura en la página de estado.

A scheduled run generates new data for the synthetic store, recomputes the KPIs, drafts the commentary and runs the check. The last run is on the status page.
