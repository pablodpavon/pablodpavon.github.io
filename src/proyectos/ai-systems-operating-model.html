Contexto

Context

SearchedBy (antes GEO Scan) es mi producto: le muestra a un negocio qué responden los asistentes de IA cuando un cliente pregunta por su rubro. Claude Code escribió casi todo el código. Yo escribí las reglas, revisé los resultados y decidí qué salía a producción.

SearchedBy (formerly GEO Scan) is my own product: it shows a business what AI assistants answer when a customer asks about its field. Claude Code wrote almost all of its code. I wrote the rules, reviewed the results and decided what went live.

Con un agente escribiendo el código, mi trabajo pasó a todo lo que lo rodea: saber qué cambió, probar que funciona, que el servidor sea idéntico a lo que probé y cuánto costó cada paso, con varias sesiones cambiando el producto al mismo tiempo. Esta página es el proceso que uso para eso.

With an agent writing the code, my work moved to everything around it: knowing what changed, proving it works, keeping the server identical to what I tested, and knowing what each step cost, while several sessions change the product at the same time. This page is the process I use for that.

El circuito

The loop

Todo cambio, desde corregir una frase hasta un arreglo de seguridad, pasa por los mismos cinco pasos. Las compuertas lo devuelven a su copia de trabajo; solo mi OK lo pasa a producción. Cada paso deja su rastro en el registro.

Every change, from fixing one phrase to a security patch, goes through the same five steps. Gates send it back to its working copy; only my OK moves it to production. Every step leaves its trace in the record.

Decisiones con número

Numbered decisions

Una sesión se puede compactar o cortar en cualquier momento, y lo que estaba solo en la conversación se pierde. Por eso cada decisión va a un único log con número, fecha, hora y fuente: mis palabras, citadas, o “decisión técnica” cuando el agente decidió dentro de reglas que yo había fijado. Al 1 de noviembre de 2026 el log, que cubre todos mis proyectos y no solo SearchedBy, tenía 155 entradas. Esta es una, recortada:

A session can be compacted or cut off at any moment, and whatever was only in the conversation is lost. So every decision goes into one log with a number, date, time and source: my words, quoted, or “technical decision” when the agent decided within rules I had set. El diario hace lo mismo con las acciones: después de cada paso, una línea con la hora de Berlín, cómo quedó y qué sigue. Cualquier sesión, local o en la nube, retoma el trabajo leyendo la carpeta.

The diary does the same for actions: after each step, a line with the Berlin time, the state it was left in and what comes next. Any session, local or in the cloud, picks up the work by reading the folder.

Tests primero, en dos versiones de Python

Tests first, on two Python versions

Los tests nuevos corren primero sobre la copia sin cambios y tienen que fallar ahí. En un cambio de experiencia de usuario del 1 de noviembre, 28 tests nuevos corrieron sobre la copia sin cambios: 27 fallaron y uno pasó, el que comprueba que las otras páginas conservan sus ejemplos, que tiene que pasar. Después del cambio, pasaron los 28.

New tests run first on the unchanged copy and have to fail there. On a user-experience change on 1 November, 28 new tests ran on the unchanged copy: 27 failed and one passed, the one checking that other pages keep their examples, which is meant to pass. After the change, all 28 passed.

Después corren las dos suites completas en Python 3.13, el de mi Mac, y en 3.12, el del servidor, cada una en su entorno con las mismas versiones de paquetes. El 1 de noviembre eran 2.684 tests del pipeline del scan y 1.184 de la web. Corren sin conexión: ninguna API paga, ningún sitio real.

Then both full suites run on Python 3.13, my Mac's, and on 3.12, the server's, each in its own environment with the same package versions. On 1 November that was 2,684 tests for the scan pipeline and 1,184 for the web app. They run offline: no paid API, no real website.

Producción no se edita en el lugar

Production is never edited in place

El trabajo se hace en una copia con fecha. La lista de archivos de un deploy se calcula contra producción, nunca contra otra copia, para que dos cambios en paralelo no se pisen. Antes de copiar nada, los originales van a una carpeta con fecha, hora y motivo. Así empieza el checklist de un deploy real:

Work happens in a dated copy. The list of files a deploy changes is computed against production, never against another copy, so two parallel changes cannot undo each other. Before anything is copied in, the originals go to a folder named with the date, time and reason. This is how a real deploy checklist starts:

Sets ciegos, una sola corrida

Blind sets, run once

Los tests unitarios muestran que cada regla hace lo que dice. No muestran si un cambio mejoró el producto en casos que nadie miró. Para la parte que lee las respuestas de la IA y detecta qué negocios recomiendan, otro agente escribe un set ciego antes de tocar el código, sin ver el código ni los sets anteriores. El archivo se firma con sha256 y corre una sola vez, sobre el candidato y sobre producción.

Unit tests show that each rule does what it says. They cannot show whether a change made the product better on cases nobody looked at. For the part that reads AI answers and finds which businesses they recommend, a separate agent writes a blind set before the code is touched, without seeing the code or earlier sets. The file is hashed with sha256 and runs once, on the candidate and on production.

Un lector nativo por idioma

A native reader for every language

La interfaz está en inglés, español, alemán y hebreo. Puedo juzgar dos de esos idiomas. Para los otros, el agente primero lee páginas reales en ese idioma (42 páginas en hebreo de 32 dominios para el primer glosario) y arma un glosario versionado donde cada término tiene un nivel de confianza. Revisores nativos contestan preguntas numeradas y agrupadas por pantalla, en un idioma que leen (a uno se le manda todo solo en hebreo), y sus respuestas se convierten en la versión siguiente. Al 1 de noviembre: hebreo v7, alemán v3, español v2.

The interface is in English, Spanish, German and Hebrew. I can judge two of those. For the others, the agent first reads real pages in that language (42 Hebrew pages from 32 domains for the first glossary) and writes a versioned glossary where every term has a confidence level. Native-speaker reviewers answer numbered questions grouped by screen, in a language they read (one gets everything in Hebrew only), and their answers become the next version. By 1 November: Hebrew v7, German v3, Spanish v2.

Un idioma queda oculto hasta su primera revisión nativa. Después, cada frase nueva sin revisar queda anotada para la ronda siguiente, y yo decido si puede salir antes.

A language stays hidden until its first native review. After that, every new phrase without review is listed for the next round, and I decide whether it can go out before then.

El costo se dice antes de gastar

The cost is stated before it is spent

Antes de cualquier scan, llamada paga o revisión con agentes, la sesión dice el costo estimado. El 24 de octubre, antes del primer scan real, la estimación con precios de lista oficiales fue de US$ 0,08 a 0,16 por scan de 10 corridas, con los volúmenes de tokens marcados como supuestos. Hoy cada corrida registra tokens, búsquedas y costo: un scan real de 15 corridas costó US$ 0,2333 el 1 de noviembre. Hay topes por scan y por día en el código.

Before any scan, paid API call or review by agents, the session states the estimated cost. On 24 October, before the first real scan, the estimate from official list prices was US$ 0.08 to 0.16 for a scan with 10 engine runs, with token volumes marked as assumptions. Each run now logs tokens, searches and cost: a real scan with 15 runs cost US$ 0.2333 on 1 November. Caps per scan and per day are enforced in code.

La misma regla limita mi propio proceso: como máximo una revisión independiente y un set ciego por deploy. Si el candidato supera con claridad a producción y no tiene errores graves, sale, y los casos de borde van a pendientes.

The same rule limits my own process: at most one independent review and one blind set per deploy. If the candidate clearly beats production and has no serious errors, it ships, and the edge cases go to the backlog.

Una auditoría de seguridad independiente

An independent security review

Antes de abrir más la beta, una sesión de Claude Code en la nube auditó la web y los scripts de deploy solo desde el repositorio, con una prueba de concepto o un test donde se podía armar. Encontró 14: 2 altos, 6 medios y 6 bajos. Otra sesión en la nube corrigió 8, los dos altos incluidos, en su propia rama y con 45 tests nuevos que fallan sobre el código viejo. La rama llegó a producción por el checklist de siempre, y después del deploy pasaron 35 tests de seguridad en el propio servidor.

Before opening the beta wider, a Claude Code session in the cloud audited the web app and the deploy scripts from the repository alone, with a proof of concept or a test wherever one could be built. It found 14: 2 high, 6 medium and 6 low. A second cloud session fixed 8 of them, both highs included, on its own branch and with 45 new tests that fail on the old code. The branch reached production through the usual checklist, and after the deploy 35 security tests passed on the server itself.

Lo que quedó es endurecimiento de servidor, red y backups, documentado como recomendaciones. El resumen público está en las notas de ingeniería, sin nada que le sirva a un atacante.

What remains is server, network and backup hardening, documented as recommendations. The public summary is in the engineering notes, with nothing that would help an attacker.

Agentes en paralelo, cada uno con su brief

Parallel agents, each with a brief

Varias sesiones trabajan a la vez: una coordina y otras toman un idioma, una mejora de experiencia de usuario o una revisión. Cada una recibe un brief escrito (base, alcance, costo y entregable) y devuelve una copia de trabajo, un checklist de deploy y un informe corto. Ninguna despliega. Las sesiones en la nube trabajan en ramas propias; sus informes llegan a mi Mac cada cinco minutos y su código entra a producción solo por el mismo checklist.

Several sessions work at the same time: one coordinates, others take a language, a user-experience pass or a review. Each gets a written brief (base, scope, budget and deliverable) and returns a working copy, a deploy checklist and a short report. None of them deploys. Cloud sessions work on their own branches; their reports reach my Mac every five minutes and their code goes to production only through the same checklist.

Lo que es mío: las reglas, la evidencia que acepto y la decisión de publicar. El resto se delega, y queda escrito.What I own: the rules, the evidence I accept and the decision to ship. The rest is delegated, and written down.

Lo que cuesta: cada respuesta del agente tarda uno o dos minutos más porque documenta mientras trabaja, y algunos cambios esperan días a un revisor nativo. Acepto las dos cosas. Es el proceso de una persona para un producto en beta abierta; todavía no lo probé con un equipo.

What it costs: every answer from the agent takes a minute or two longer because it documents as it works, and some changes wait days for a native reviewer. I accept both. This is one person's process for one product in an open beta; I have not run it with a team yet.
